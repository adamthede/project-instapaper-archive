💡 Technical Decision: LLMs over Traditional ML

Traditional Approach

❌ Train separate models for:

• Text classification

• NER (spaCy, BERT)

• Sentiment (custom models)

• Summarization

Weeks of training, GPU costs, model maintenance

LLM Approach (Chosen)

✅ One API for everything:

• Gemini 1.5 Flash

• Structured JSON output

• Prompt engineering

• Zero training required

$0.50 total, 30 minutes processing time

Leveraged modern LLMs for tasks that would've required multiple ML pipelines

📄 Document Conversion Pipeline

Multi-format → Unified Markdown

Primary Path

MarkItDown (Microsoft's open-source tool)

PDF, DOCX, HTML, TXT, RTF → Markdown

Fallback Path (Legacy .doc)

LibreOffice (headless CLI) → DOCX

Then: MarkItDown → Markdown

Subprocess management, timeout handling, temp file cleanup

All outputs: Markdown + YAML frontmatter with metadata
